# Update notices and bundled system icons

The host updater previously cleared available=true at the start of each GitHub check. Polling during that check could temporarily remove the update icon and notification, and a failed fetch could leave the previously known update hidden. The worker now retains a previously detected newer commit through checking or fetch failure and recomputes availability only after a successful fetch. Its timer runs after each service completion so a long fetch does not consume the next scheduled interval. Setup requests an immediate background check.

The API reports stale/missing configured worker status explicitly. Owners receive an actionable bell warning instead of silently losing updater status. A configured stale worker can be asked to check again, while installation still requires recent healthy worker status. The header keeps known availability visible while checking, announces newly detected releases and refreshes the bell. About offers Check for Updates rather than Install Update when availability is not currently installable. Completion with no available update removes the update control as requested.

The 61 system/provider/OS brand icons and 11 page icons now use bundled PNG data generated from the existing licensed SVG artwork. This removes their independent image requests, which previously could trigger generic SVG fallbacks on image load failure. Unknown identities retain neutral placeholders. Source SVGs, credits and license records remain available. PNGs retain transparency and are optimized at 192 pixels. A separate ~285 kB raw icon module keeps the main application chunk near its previous size. The reproducible generator requires Python, CairoSVG and Pillow only when regenerating artwork; normal installation builds use the checked-in data.

Validation includes host-worker fixtures for checking, failed fetch, successful install and failure cleanup; API tests for stale worker warnings and recheck requests; UI tests for initial availability announcements, checking visibility, completion hiding and stale-worker rechecking; all PNG headers/dimensions and source coverage; visual inspection of six representative icons; full API/web tests, targeted final update UI tests and the production build. No live user VM update-service logs or physical browser session were accessed, so the specific installation's failure cause remains unconfirmed.
